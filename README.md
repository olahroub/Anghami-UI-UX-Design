# تصميم واجهات تطبيق أنغامي | Anghami UI/UX Design

مشروع تصميم واجهات مستخدم وتجربة مستخدم (UI/UX) متكامل يحاكي تطبيق الموسيقى الشهير "أنغامي"، تم بناؤه وتخطيطه باستخدام برنامج **Adobe XD**. يتضمن المشروع نسختين بأنماط وألوان مختلفة (الأزرق والأحمر) لتقديم تجارب بصرية مرنة وعصرية.

An integrated UI/UX design project replicating the famous music app "Anghami", created and prototyped using **Adobe XD**. The project showcases both Blue and Red color themes to demonstrate design flexibility and user interface planning skills.

## ميزات التصميم | Design Highlights
* **تنوع الأنماط البصرية (Multi-Theme Design):** تقديم واجهات كاملة بنمطين لونيين مختلفين لضمان مرونة الهوية البصرية للتطبيق.
* **تصميم عصري (Modern UI):** تخطيط مريح لصفحات التسجيل، القوائم الموسيقية، ومشغل الأغاني يتوافق مع أحدث معايير تجربة المستخدم (UI/UX).
